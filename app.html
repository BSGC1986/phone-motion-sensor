📲 Motion Games — Android app

The web page stops sending when a phone's screen turns off. This small app keeps the sensors running with the screen off, so a phone can sit in a ball without the screen being on. Android only.

⬇ Download the app (152 KB)

1. Install it

  1. Open the downloaded file motiongames.apk (from the notification or the Downloads app).
  2. Android will say it can't install apps from this source. Tap Settings and switch on Allow from this source, then go back.
  3. If Play Protect warns about an unrecognised app, tap More details → Install anyway. The app isn't from the Play Store, so this is expected.

2. Join a game

  1. On the PC, open the site and note the 6-character game code.
  2. Open Motion Games on the phone, type the code, and tap Start sensor. (Allow notifications when asked.)
  3. Tap Allow running in the background and choose Allow. This is the important one.
  4. Put the phone in the ball. You can turn the screen off — a notification shows while the sensor runs. Tap Stop in the notification (or in the app) when you've finished.

Shortcut: if you scan the QR code with the phone and the web page opens, tap 📲 Open the app and the code is filled in for you.

If it stops when the screen is off

  • Settings → Apps → Motion Games → Battery → choose Unrestricted (on some phones: Don't optimise).
  • Samsung: Battery → Background usage limits → Never sleeping apps → add Motion Games.
  • Xiaomi / Huawei / OnePlus / Oppo: also switch on Autostart and lock the app in the recent-apps list.
  • The phone needs Wi-Fi or mobile data to reach the PC.

iPhones can't run this app. They can use the web page instead (with Dim screen, which keeps the screen on but black).
